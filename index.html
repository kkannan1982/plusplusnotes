Frequently asked questions

Where are my notes stored?
Each note is a plain Markdown (.md) file in the app's Documents folder on your Mac, under NotePlus. Nothing is uploaded anywhere.
Do I need to save?
No. Every note autosaves a moment after you stop typing. The status bar shows when a note is saved.
How do I copy a code block?
Hover over a fenced code block and click the copy button, or right-click inside it and choose Copy Code Block.
How do I switch between light and dark?
++Notes follows your system appearance by default. You can also pick Light or Dark from the app's appearance setting.
Can I open my notes in another app?
Yes. They are ordinary Markdown files, so any text editor or Markdown app can open them.
